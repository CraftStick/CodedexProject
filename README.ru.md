# GIF Generator in Python

[English](README.md) · [Русский](README.ru.md)

Python-скрипт, который собирает анимированный GIF из двух PNG-изображений.

## Начало работы

Нужен Python 3 и `imageio`: `pip install imageio`.

## Использование

```bash
cd VSCodeMacPython
python3 creat_a_gif.py
```

## Структура проекта

- `VSCodeMacPython/creat_a_gif.py` — скрипт, создающий GIF
- `VSCodeMacPython/image1.png`, `image2.png` — кадры анимации
- `VSCodeMacPython/team.gif` — результат
